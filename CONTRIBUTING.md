# Contributing

Thanks for your interest in ui-clips.

- **Open an issue first.** Describe the problem or the change before writing code, so the approach can be agreed.
- **Pull requests come from forks.** Fork the repository, branch from `main`, and open a pull request against `main`.
- **One change per pull request.** Keep the diff to the one thing the issue describes; add a `CHANGELOG.md` line and a test for any behaviour change.
- **Checks that must pass:** `npm test` and `claude plugin validate --strict .`.
- **`main` is protected.** It merges only with the owner's approval (`@banuakman`, see `.github/CODEOWNERS`).
- **Licence.** Contributions are made under the Apache License 2.0 (see `LICENSE`); by opening a pull request you agree to that.
